# Code of Conduct

## Scope

This project uses the [Microsoft Open Source Code of Conduct](https://opensource.microsoft.com/codeofconduct/) as its participation standard. It applies to documentation and code contributions, pull request reviews, and project-related discussions. Adopting this standard does not imply that Microsoft owns this repository or handles reports for it.

## Participation Guidelines

- Respect participants with different backgrounds and levels of experience, and welcome questions and contributions.
- Focus reviews on the proposed changes and their rationale, not on the person who submitted them.
- Do not engage in harassment, threats, discriminatory language, or the disclosure of personal information without consent.
- When disagreements arise, listen to other viewpoints and discuss them using technical evidence.
